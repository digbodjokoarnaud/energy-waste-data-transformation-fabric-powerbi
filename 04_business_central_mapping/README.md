# 04 — Mapping vers Microsoft Dynamics 365 Business Central

Cette étape prépare le pont entre les anciens fichiers Excel métiers et les objets Business Central.

## Objets ciblés

- Customer
- Sales Invoice
- Customer Ledger Entry
- Items
- Resources
- Dimensions
- Dimension Values
- Jobs / Service Contracts selon paramétrage

## Objectif

Déterminer quelles données doivent aller dans Business Central et quelles données doivent rester dans Fabric pour l’analyse.
