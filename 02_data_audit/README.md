# 02 — Audit qualité des fichiers Excel

Cette étape analyse la qualité des fichiers Excel métiers avant toute migration.

## Contrôles réalisés

- valeurs manquantes
- doublons
- types de données incohérents
- statuts non normalisés
- anomalies métier
- relations orphelines entre clients, contrats et factures

## Objectif

Prioriser les corrections avant intégration dans Business Central, Microsoft Fabric ou Power BI.
