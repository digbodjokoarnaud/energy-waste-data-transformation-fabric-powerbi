# 01 — Génération des fichiers Excel métiers

Cette étape génère des fichiers Excel simulés pour un contexte énergie / environnement.

## Fichiers générés

- Clients
- Contrats
- Tonnages déchets
- Valorisation énergétique
- Facturation
- Maintenance
- Suivi migration Excel

## Anomalies simulées

Les données contiennent volontairement des anomalies réalistes :

- doublons
- valeurs manquantes
- dates incohérentes
- montants au format texte
- statuts non normalisés
- tonnages négatifs
- factures payées sans date de paiement
- contrats actifs expirés
